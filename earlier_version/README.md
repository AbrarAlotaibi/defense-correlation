# Earlier version

Material from the earlier and longer manuscript that reported a first version of this
experiment (arXiv:2608.28327). It is kept for the record. The current paper does not use it,
and its headline numbers are superseded: the harness that produced them had four defects,
listed at the top of [REPRODUCING.md](../REPRODUCING.md).

| Path | Contents |
| --- | --- |
| `paper/` | Text inserts, figures and two supplementary analyses written for that manuscript |
| `fusion/` | Classifier-fusion recast of its results: diversity measures and combination rules |
| `PREREGISTRATION.md` | The hypotheses and decision rules fixed before those runs, with one dated amendment |

The runs behind this material are `results/hpc_*` and `results/primary_*`, with the matching
files in `configs/`. The scripts that produced it are listed under "Earlier version" in
[scripts/README.md](../scripts/README.md).
